# Acortador de URL con Tracking

Esta aplicación te permite acortar enlaces largos y ver estadísticas de cuánta gente los visita. Incluye todo lo necesario para funcionar en tu ordenador con una interfaz web simple.

## Requisitos

- **Python instalado** en tu ordenador. (Descárgalo en [python.org](https://www.python.org/downloads/)).

## Cómo usarlo (Fácil)

No necesitas usar la terminal. He creado unos archivos de inicio automático:

### En Windows
1. Haz doble clic en el archivo `start.bat`.
2. Se abrirá una ventana negra (no la cierres) y automáticamente se abrirá tu navegador con la aplicación lista para usar.

### En Mac / Linux
1. Abre el archivo `start.sh` (o ejecútalo desde la terminal con `./start.sh` si sabes cómo).
2. La aplicación se iniciará y abrirá tu navegador.

---

## Cómo usar la aplicación

1. **Acortar:**
   - Pega tu enlace largo en el recuadro.
   - (Opcional) Ponle un nombre corto (ej: `miapp`).
   - Dale a "Acortar".

2. **Compartir:**
   - Copia el nuevo enlace que aparece.

3. **Ver Estadísticas:**
   - Haz clic en "Estadísticas" en el menú de arriba para ver cuántos clicks llevan tus enlaces.
